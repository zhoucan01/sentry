## ? 工程一：`大yaw_感知相机` — 导航决策 + 大云台控制

> **核心职责**: 哨兵大脑 — 自主导航决策、地图点位管理、裁判系统交互、大Yaw轴云台控制、迷你PC通信

### 硬件
| 组件 | 型号 | 角色 |
|------|------|------|
| 主控 | STM32F407IGHx | 决策 + 大Yaw控制 |
| 大Yaw电机 | 6020 | 水平旋转云台，带动整个上部结构 |
| IMU | BMI088 | 姿态解算，提供 Yaw 角参考 |
| 迷你PC | USB虚拟串口 | 运行视觉算法 + SLAM导航 |

### FreeRTOS 任务
| 任务 | 周期 | 功能 |
|------|------|------|
| `Auto_run` | 1ms | 主动决策循环：裁判数据→条件判断→模式选择→点位填充→发导航 |

### 决策架构

哨兵行为由 **6 种决策模式 + 14 个地图点位** 组成状态机。每种模式定义了一组点位转移规则，根据战场条件（血量、弹量、敌方前哨站状态、基地护甲等）自动切换点位。

```
                    ┌─────────────┐
               ┌───→│  extreme    │←───┐
               │    │  激进模式    │    │
               │    └──────┬──────┘    │
               │           │转移规则    │
          ┌────┴───┐  ┌───┴───┐  ┌────┴───┐
          │conserv.│  │patrol │  │ flying │  ...
          │ 保守   │  │ 巡逻  │  │ 飞坡   │
          └────────┘  └───────┘  └────────┘
               ↑           ↑          ↑
               └───────────┴──────────┘
                    遥控器 S_L/S_R 组合选择
```

### 6 种决策模式

| 模式 | 遥控器 | 核心策略 | 涉及点位 |
|------|--------|----------|----------|
| `extreme` | S_L=1,S_R=1 | 全力进攻：打前哨→上敌方堡垒→退守己方 | 前哨站/补给区/堡垒/高地/巡逻 |
| `conservative` | S_L=3,S_R=3 | 稳健防守：飞坡打前哨→守堡垒 | 飞坡点/前哨站/补给区/巡逻 |
| `patrol` | S_L=3,S_R=1 | 有限进攻：只打前哨站，不上敌方高地 | 前哨站/补给区/高地/巡逻 |
| `flying` | S_L=3,S_R=2 | 飞坡机动：飞坡落点+打前哨 | 飞坡点/前哨站/补给区/高地 |
| `protect` | S_L=1,S_R=3 | 区域保护：守飞坡+前哨站保护 | 飞坡点/前哨站/补给区 |
| `air_control` | 上位机标点 | 云台手远程操控：手动标点导航 | 手动点/补给区 |

### 控制流水线

每 2ms 执行一次完整控制循环：

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ ① 坐标系旋转  │───→│ ② 逆运动学   │───→│ ③ 舵角解算   │
│ 云台系→底盘系 │    │ vx/vy/ω→四轮 │    │ atan2+劣弧   │
└──────────────┘    └──────────────┘    └──────┬───────┘
                                               │
┌──────────────┐    ┌──────────────┐    ┌──────↓───────┐
│ ⑥ 功率限制   │←───│ ⑤ PID 级联   │←───│ ④ 速度合成   │
│ 超电自适应   │    │ 位置→速度→电流│    │ 方向+cos?衰减│
└──────────────┘    └──────────────┘    └──────────────┘
```

#### ① 坐标系旋转 `RotateSpeedToBase()`
将云台坐标系下的目标速度 $(v_x^g, v_y^g)$ 旋转到底盘坐标系：
$$v_x^b = v_x^g\cos\Delta\theta + v_y^g\sin\Delta\theta$$
$$v_y^b = -v_x^g\sin\Delta\theta + v_y^g\cos\Delta\theta$$

#### ② 逆运动学分解 `chassis_speed_get()`
四轮位于正方形四角，半径 $R$，舵角 $\theta_i$ 时：
$$v_i = v_x^b\cos\theta_i + v_y^b\sin\theta_i \pm R\omega\sin(\pi/4)$$

#### ③ 舵角解算 `steer_angle_get()`
- `atan2(vy, vx)` → 目标舵角 (rad)
- 转换为编码器值 (0~8191)
- **劣弧优化**：选择最短旋转路径，偏差 > 90° 则反转 180° + 轮速反向
- `no_move` 模式下锁舵，`move_flag=0` 时保持上次舵角

#### ④ 速度合成 `chassis_speed_set()`
- 四轮线速度合成：$|v_i| = \sqrt{v_{ix}^2 + v_{iy}^2}$
- 方向修正：劣弧优化后轮速取反
- **cos?衰减**：非陀螺时，舵角未到位则 $v_i' = v_i \cdot \cos^3(\Delta\theta)$

#### ⑤ PID 级联 `chassis_clac()`
```
舵角目标ecd ──→ [舵角P] ──→ 舵速目标 ──→ [舵速P] ──→ 舵机电流
轮速目标rpm ──→ [轮速PID] ──→ 底盘电机电流
```
- 舵角位置环：P=0.5, 限幅 400~500
- 舵速环：P=50~55, 限幅 16384
- 轮速环：P=5.0, I=0.1, 限幅 2500~4000

#### ⑥ 功率限制 `chassis_power_limit_set()`
基于电机功率模型 $P = k_p I\omega + k_w\omega^2 + k_i I^2 + C$ 进行自适应限功率：

1. **读取缓冲能量**：裁判系统功率缓冲 ? PID调节
2. **超电检测**：超电电压 > 13.5V → 额外 +60W
3. **舵机优先**：上限 = 总功率 × 80%，超限则等比例缩电流
4. **底盘分配**：剩余功率 (扣3W余量) 分配给四个 M3508
5. **反解电流**：$k_i I^2 + k_p\omega \cdot I + (k_w\omega^2 + C - P_{target}) = 0$

### 里程计观测器 `Odometer.c`
基于线性卡尔曼滤波，参考 Batch-LIWO 论文：

- **状态**: $x = [v_x, v_y, \omega]^T$
- **测量**: 四轮编码器 → 轮速 $z = [v_0, v_1, v_2, v_3]^T$
- **自适应噪声**: $R_{ii} = r_{base} + k \cdot \text{loss}_i$（打滑轮子自动降权）
- 八步流程：读编码器→构建H矩阵→卡尔曼预测→最小二乘→RMS残差→自适应R→卡尔曼更新→云台角

### 云台控制

#### 三模式切换
| 模式 | 触发条件 | 行为 |
|------|----------|------|
| `small_gimbal_off` | 通信离线/遥控关闭 | 电流清零，角度锁定 |
| `small_gimbal_rc` | 遥控器控制 | 摇杆增量式角度控制 |
| `small_gimbal_pc` | PC视觉模式 | 视觉追踪 + 巡航 |

#### 视觉追踪模式
```
vision_frount (前方发现目标)
    ├── lock_state == no_lock  → 直接追踪
    ├── lock_state == left_lock  → 反向巡航释放限位
    └── lock_state == right_lock → 反向巡航释放限位

vision_back (后方有目标)
    → 不处理（由大Yaw负责转过来）

vision_lost (目标丢失)
    → 进入巡航模式：持续旋转搜索目标
```

#### PID 参数
| 环 | P | I | D | 限幅 | 说明 |
|----|---|---|---|------|------|
| Yaw位置环 | 2.0 | 0 | 0 | 70 | 角度跟踪 |
| Yaw速度环 | 400 | 0 | 0 | 30000 | 高速响应 |
| Pitch位置环 | 0.28 | 0 | 0 | 5 | 俯仰跟踪 |
| Pitch速度环 | 0.3 | 0 | 0 | 8 | 俯仰平滑 |

### 射击控制

#### 摩擦轮转速模型
```
目标转速 = 基准转速(FRICTION_L3_SPEED) + 射速补偿 + 温度补偿
```

| 补偿项 | 说明 |
|--------|------|
| 射速补偿 `shoot_speed_fix` | 根据实际弹速自适应调节 (SpeedAdapt) |
| 温度补偿 `shoot_tem_fix` | 温度每升高 1°C，转速补偿 0.5 rpm |

#### 射速自适应 `SpeedAdapt()`
```
if 实际弹速 < MIN_SPEED → 累计计数
if 计数达到阈值 → 补偿值 + UP_NUM (提高转速)
if 实际弹速 > MAX_SPEED → 补偿值 - DOWN_NUM (降低转速)
if MIN ≤ 实际 ≤ MAX → 计数清零（转速合适）
```

#### 拨弹逻辑
- `shoot_on`：摩擦轮加速到位 → 拨弹电机触发 → 单发/连发
- `shoot_no`：摩擦轮停转，拨弹停止

### 离线检测 `DETECT_task`
监控 8 路设备的 CAN 通信心跳：
```
摩擦轮R / 摩擦轮L / 拨弹 / Yaw / Pitch / 遥控器 / 视觉 / 主控板
```
任一设备超时未收到数据 → 标记 `COMMUNICATION_NONE` → 触发安全保护
